# AI-Powered Interview Coach

An AI-powered interview preparation platform that helps users practice technical interviews, manage interview sessions, and evaluate their performance.

## 🚀 Live Demo

[Click here to use AI Interview Coach](https://ai-interview-1-ziyk.onrender.com)

## 🛠️ Technologies Used

- React.js
- JavaScript
- CSS
- Python
- Flask
- SQLite
- RESTful APIs
- JWT Authentication

## ✨ Features

- User Registration and Login
- AI-powered Interview Questions
- Technical Interview Practice
- Resume-based Interview
- Job Description-based Interview
- Interview History
- Performance Reports
- Score Evaluation

## 📂 Project Structure

- `frontend/` - React frontend
- `backend/` - Flask backend

## 🌐 Deployment

The application is deployed using Render.
